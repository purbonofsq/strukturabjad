# Struktur Abjad Old Backend

A minimal Python backend starter built with Flask.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Available routes:
- `GET /`
- `GET /health`
- `GET /api/hello`

The app runs on http://127.0.0.1:5000
